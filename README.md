# Sunny Star Landscaping LLC Website

A responsive React + Vite website redesign based on the Sunny Star Landscaping LLC company portfolio.

## Run locally

Requirements: Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Main pages

- Home: service overview, approach, selected projects and contact CTA
- Services: landscaping, maintenance, lawn care, irrigation and planting
- Projects: selected portfolio projects
- Areas: service area information
- About Us: company information
- Contact: contact details and enquiry options
